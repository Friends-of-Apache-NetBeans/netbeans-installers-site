Welcome! We're Friends of Apache NetBeans, and we build ready-to-go packages and installers for Apache NetBeans so you can get coding faster. We put them together straight from the official Apache NetBeans binary release — just note they're our builds, not official releases from the Apache Software Foundation, which cannot release these kinds of packages and installers. However, each release of our installers is created, tested, and approved by members of the Apache NetBeans PMC (Project Management Committee), the same people who build, test, and approve Apache NetBeans itself.

Best of all, there's nothing else to install: every download here comes with a Java JDK built right in{% if jdkname != "" %} — {{ jdkname }} {{ jdkver }}, paired with Apache NetBeans {{ latest }}{% endif %}, so the IDE just works out of the box. Need a different JDK for your projects? No problem — add or download more anytime from the Java Platform dialog (in the Tools menu).
